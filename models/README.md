# Optional brain 3D model

The portfolio renders a **procedural brain** by default. To use a custom mesh:

1. Download a `.glb` or `.gltf` brain model (CC0 or licensed for your use).
2. Save it as `brain.glb` in this folder (`public/models/brain.glb`).
3. Reload the site — the app checks for the file and loads it when present.

If the file is missing or fails to load, the procedural brain is shown automatically.
